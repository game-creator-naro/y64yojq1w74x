# 無題のゲーム

▶ 遊ぶ: https://gcn-play.com/play/y64yojq1w74x
（このゲームが公開されていない間、上の URL は開けません）

[ゲームクリエイターになろう](https://gcn-play.com) で AI とチャットして作られたゲームです。

## ブランチ

- `main` — 公開中の版のスナップショット（「みんなが作ったゲーム」に並んでいるもの）
- `develop` — 制作中の最新版のスナップショット

`develop` が `main` より進んでいるときは「未公開の更新」という Pull Request が自動で作られます。
**この PR を GitHub 上でマージしないでください** — 公開はプラットフォームの「公開」ボタンだけが行い、
押されたときにその版のコミットが `main` へマージされます。

## このリポジトリの中身

- `index.html` — ゲーム本体。素材をすべて埋め込んだ自己完結ファイルで、**ブラウザで開くだけで遊べます**。
- `assets/` — ゲームが使っている画像・音声・動画・3D モデルの**原本**（カテゴリ別）。
- `game-manifest.json` — 収録ファイルの一覧（パス・MIME・バイト数・SHA-256）。

緑の `Code` ボタン →「Download ZIP」でまとめてダウンロードできます。
展開して `index.html` を開けば、そのままオフラインでも遊べます。

（`game-manifest.json` 自身のハッシュは、自分自身には書けないため一覧に含まれません。）
